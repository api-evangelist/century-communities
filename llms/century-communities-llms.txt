# Century Communities

> Century Communities, Inc. (NYSE: CCS) is one of the largest homebuilders in the United
> States, building and selling single-family homes across roughly twenty states under the
> Century Communities and Century Complete brands, with in-house mortgage (Inspire Home
> Loans), title (Parkway Title) and insurance arms. It is a homebuilder, not a software
> company, and it runs no developer program.

## What is actually callable

Century Communities publishes no developer portal, no API documentation, no OpenAPI, and
no SDK. The hosts a previous profile recorded — api.centurycommunities.com and
developer.centurycommunities.com — do not exist (NXDOMAIN, 2026-09-14) and have been
removed.

One machine-readable surface is nonetheless live and answers without credentials: the
Optimizely (Episerver) Content Delivery API v3.0 that the company's public marketing site
exposes. It serves the website's own content tree — pages, blocks, assets, site and host
bindings — and nothing about homes, communities, pricing or inventory beyond what those
pages contain.

- Base: https://www.centurycommunities.com/api/episerver/v3.0
- GET /site — the site definition: name, id, nine content roots, one language, 60 host bindings
- GET /site/{siteId} — one site definition
- GET /content/{id} — one content item, with its contentType, parentLink and typed properties
- GET /content?contentUrl={page url} — resolve a public page URL to its content item
- GET /content?references={id} — the items referencing a given item
- Read-only: POST and DELETE both return 405

## How it behaves

- Anonymous read. No key, no token.
- Errors: RFC 9457 application/problem+json with type, title, status, detail, instance,
  traceId and code — except a non-numeric id, which falls through to the HTML 404 page.
- Caching: ETag plus Cache-Control public, s-maxage=5; If-None-Match returns 304.
- No pagination, no rate-limit headers, no Retry-After.
- Ids are sequential integers, so the published tree is enumerable.

## Authentication (for the private surface)

An OpenID Connect authorization server runs on the same host for clients Century Communities
provisions privately. There is no self-service registration.

- Discovery: https://www.centurycommunities.com/.well-known/openid-configuration
- Also at: https://www.centurycommunities.com/.well-known/oauth-authorization-server
- JWKS: https://www.centurycommunities.com/.well-known/jwks
- Issuer: https://www.centurycommunities.com/
- Grants: authorization_code (PKCE S256), refresh_token, client_credentials
- Scopes: openid, offline_access, profile, email, roles, epi_service_api
